About The Dataset

A comprehensive, open-source dataset of the Indian Railways network.

Disclaimer: Static Data Demonstration

The tracking, booking, PNR, and station data shown on this website is completely static and based on an open-source JSON dataset. There are no live status updates, and no real tickets are booked. This is purely a UI/UX demonstration of a modern railway application.

Dataset Overview

TrackEase is powered by a high-quality open dataset containing two primary entities: Stations and Trains. The data has been parsed, indexed, and ingested into a local SQLite database for blazing-fast search and API performance, preventing the need to download 96MB of raw JSON in the browser.

Schema Glossary

Station Model
Field Type Description
codeString (PK)Unique 3-4 letter alphanumeric station code (e.g., CSTM)
nameStringFull name of the railway station
city / stateStringGeographical location details
zoneStringIndian Railways Zone abbreviation (e.g., CR, WR)
addressTextFull physical address of the station
latitude / longitudeFloatGPS coordinates used for the interactive Station Explorer map
Train & Route Model
Field Type Description
numberString (PK)Unique 5-digit train number (e.g., 12951)
nameStringOfficial name of the train (e.g., Mumbai Rajdhani)
train_typeStringClassification (EXPRESS, LOCAL, SUPERFAST, PASSENGER)
running_daysJSONBoolean mapping for weekly schedule (e.g., {"MON": true, "TUE": false})
source / destinationFK (Station)The origin and terminus stations of the train
route_stationsArrayOrdered list of all halts including arrival_time, departure_time, and distance
